# Your IB Math Learning Platform

Welcome — this is the home for your new website.

## Where everything is saved

All project files live in this folder. You can open this folder in VS Code and see every file that Codex creates or changes.

The product idea you shared is saved in `PRODUCT_BRIEF.md`.

## What to do next

Open this folder in VS Code, then use Codex and write in plain English. For example:

> Create the first version of this website from the product brief. Start with a student home page, use sample content, and make it polished and easy to use.

Codex can create the files for you. After each change, ask it to explain what it made in simple language and show you how to view it.

## A simple way to work

1. Tell Codex what you want in everyday language.
2. Ask it to build that one piece.
3. Ask it to show you how it looks.
4. Say what you would like changed.

You never need to write code yourself unless you want to learn it.
